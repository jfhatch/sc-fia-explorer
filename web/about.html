About the SC FIA plot explorer

A map and plot-by-plot history of South Carolina's Forest Inventory and Analysis (FIA) plots: every visit, tree, condition and the decoded field codes, with species composition, growth, mortality, ingrowth and invasive plants over time.

Public data only

Everything here comes from the public FIADB DataMart (USDA Forest Service) CSV files for South Carolina plus the FIADB reference tables. No confidential data, true plot locations or landowner information are used. Codes are decoded from the FIADB User Guide v9.4 and the REF tables; a value that is not in those sources is shown flagged (⚠) and is never guessed. This is not an official Forest Service product.

Caveats

  • Fuzzed and swapped coordinates. Public FIA plot coordinates are altered to protect plot integrity and landowner privacy: locations are fuzzed (usually within 0.5 mi, some up to 1 mi), and for a share of private plots the coordinates are swapped with another similar plot in the same county. A marker is therefore not the plot's true location, and the plot nearest to a point you search for may not be the one physically nearest.
  • Unadjusted per-acre values. Per-acre numbers are single-plot expansions, Σ(value × TPA_UNADJ), without stratum adjustment (POP_STRATUM.ADJ_FACTOR_*). They describe one plot and are not population estimates. A sapling on a 6.8-ft microplot represents about 75 trees/ac and a tree ≥5 in on a 24-ft subplot about 6 trees/ac, so single trees move per-acre values a lot.
  • Periodic designs. Pre-annual (periodic, variable-radius) plots used different designs; their per-acre values are not comparable with national-design (annual) visits.
  • Inferred predecessors. Periodic plots are not linked to annual plots in FIADB. The site lists inferred candidates, not database links: periodic plots in the same county within 1.5 mi (public coordinates) whose last measurement date plus the first annual visit's remeasurement period is within 0.5 yr of that visit, scored by matching bridge trees, date fit and distance.
  • Additions are not all ingrowth. Ingrowth is RECONCILECD 1. Trees added for other reasons (for example when the microplot was relocated) are shown separately.
  • Bridge records (TREE rows on SUBP > 4, periodic-to-annual GRM records) are shown but excluded from totals.

Privacy

No analytics, no cookies, no third-party scripts; all JavaScript libraries (Leaflet, Leaflet.markercluster, Plotly) are served from this site. The location search runs entirely in your browser: the point you enter is not sent anywhere, not stored and not added to the address bar. The only outside requests are map tiles from USGS The National Map (basemap.nationalmap.gov), which receives the map area you view; the Plain basemap makes no tile requests.

Updates

The site is rebuilt automatically each month when the FIADB DataMart publishes new South Carolina data. Each build is validated (row counts, key relationships, regression totals for a reference plot, and an automated test suite) before it is published.
